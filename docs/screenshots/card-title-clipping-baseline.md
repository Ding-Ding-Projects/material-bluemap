# Flexed card-title clipping baseline

These captures record the real Worldlens desktop application before the shared responsive
card-title completion was rebuilt. The renderer was built from `b4b9a47f889efe35ad96da9681e91e93777d5edc`.
It was launched on the cheap Lowlevel off-screen desktop `worldlens-clipping-phase-a`; navigation
and first-run completion used background input, and every PNG was captured directly from the
freshly resolved `Worldlens` window handle. The user's visible desktop, cursor and focus were not
used.

The disposable profile deliberately supplied no GitHub token and invented no active operation.
For data-dependent rows, the capture therefore shows the exact owning surface and its truthful
empty or blocked state. It does not claim to reproduce a populated row, and those issues remain
open until the post-fix packaged matrix captures the actual long-text row.
